# Grocery-app

## Description
This a list app where you can add your groceries when you go shopping. It helps you keep an overview of what you need and how to 
much the items you want to buy will cost.

## How to install
```
git clone repo
npm install 
npm run dev 
```

## Tech stack
With this app i used express.js with supabase database. For the css i used the SCSS, together with vanilla, js and the 
sortable.js library to add the option to rearrange the list item on the list.

### Features
- [x] Overview of all groceries item with images
- [x] list overview.
- [x] Option to add items in the list.
- [x] Option to delete items from list.
- [x] Option to rearrange items on the list.
- [x] Calculate the price of all the groceries combined.
- [X] Calculate the total items inside the list.
